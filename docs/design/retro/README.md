# Handoff: мессенджер «Олег» — ретро-темы (Винамп · DOS · Денди · Дача · Микс)

## Overview
«Олег» — камерный мессенджер для друзей и семьи (5–30 человек), шуточная пародия на государственный мессенджер МАКС. Слоган: «Ненациональный мессенджер Олег». Платформы: iOS (PWA), Android, веб. Удобство уровня Telegram, но с юмором ретро-эпохи.

В пакете **пять визуальных тем** для одного и того же набора из **23 экранов**:

| Тема | Файл | Префикс | Идея |
|---|---|---|---|
| Винамп | `oleg-winamp.dc.html` | W | скин плеера 1999: тёмный металл, LCD-зелёный, эквалайзер, бегущая строка |
| DOS | `oleg-dos.dc.html` | C | зелёный фосфор + панели Нортон Коммандера, F-клавиши |
| Денди | `oleg-dendy.dc.html` | N | 8-бит, NES-палитра, пиксельный шрифт, кирпичики, «картриджи» |
| Дача | `oleg-dacha.dc.html` | D | ковёр на стене, клеёнка, ламповый радиоприёмник, тёплый свет |
| Микс | `oleg-mix.dc.html` | M | «компьютерный клуб на даче, 2001»: ковёр + металл Винампа + фосфор DOS + кнопки Денди |

**Рекомендация по архитектуре:** реализовать один набор экранов/компонентов и тему как слой токенов + несколько тематических «вариантов» компонентов (пузырь, кнопка, панель, поле, таб-бар). Структура и логика экранов во всех пяти темах одинаковые; отличаются только оформление и копирайт-шутки. Тема выбирается в Настройках (экран 20 — там показан и выбор «шкурки»).

## About the Design Files
Файлы в пакете — **дизайн-референсы, сделанные в HTML**: макеты, показывающие внешний вид и поведение, а не продакшен-код. Задача — **воссоздать их в целевом окружении** (React/Next, Vue, SwiftUI, React Native…) по его принятым паттернам. Если кодовой базы нет — рекомендуем React + TypeScript, PWA с service worker и Web Push, WebRTC для звонков.

Открыть макеты: положить папку целиком, открыть `*.dc.html` в браузере (рядом должны лежать `support.js` и `uploads/`). Это холст с артбордами; каждый подписан id (W01…W23 и т.д.). Разметка — inline-стили, все точные значения можно снять прямо из исходника.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, радиусы, тени и копирайт — финальные. Иконки — простые inline SVG/символы (можно заменить на библиотеку с тем же весом). Видео/камера — полосатые заглушки.

## Общие размеры
- Телефон: 390×844, статус-бар 54px, нижняя безопасная зона 26–34px.
- Шапка экрана: статус-бар + строка 52–58px. Поле ввода: высота 40, кнопка микрофона/камеры 44. Таб-бар 80–86px.
- Пузыри: max-width 80% (веб — 70%), padding ≈ 7–8px 11–12px, **flex-shrink: 0** у каждого элемента ленты (лента прижата к низу, `justify-content: flex-end`).
- Широкий экран (≥768): макет 1280×820, левая колонка 360–380px, лента max-width 720 по центру.

## Темы: токены и рецепты

### Винамп (W)
- **Шрифты:** Russo One (заголовки, кнопки), PT Sans 400/700 (текст, 15/1.38 в пузырях), PT Mono (LCD, время, таймеры).
- **Цвета:** фон #1B1D25 + сканлайны `repeating-linear-gradient(0deg, rgba(255,255,255,.025) 0 1px, transparent 1px 3px)`; панель `linear-gradient(#454A5C,#2C2F3B)`; LCD-фон #050805, LCD-текст #3CFF5A (тусклый #2E8B3A); акцент amber #F2A51A, кнопка `linear-gradient(#FFC84A,#E08A00)` текст #2A1600; «да» `linear-gradient(#5CE06A,#1F9A2E)` текст #062A0A; danger #FF3B3B / отбой `linear-gradient(#FF6A6A,#C41A1A)`; текст #E6E9F2, вторичный #9AA0B4 / #8A90A6.
- **Скос (bevel):** `border:1px solid; border-color: <светлый> <тёмный> <тёмный> <светлый>` — панели #6A7088/#14151B, кнопки #7A809A/#121318, LCD-поля инвертированно #121318/#5A6078. Радиусы 0 (кроме телефона и кружков).
- **Тайтлбар-полоска:** 20px, по бокам `repeating-linear-gradient(0deg,#D9B44A 0 1px,transparent 1px 3px)` высотой 7, по центру Russo One 11px .24em #E8D9A0 («ОЛЕГАМП», «ПЛЕЙЛИСТ», «НА СВЯЗИ»…).
- **Эквалайзер:** столбики `linear-gradient(to top,#2ECC40 0 55%,#F2D21A 55% 80%,#FF3B3B 80%)`.
- **Пузыри:** чужой — панель-градиент `#3C4152→#2C2F3B` с bevel, имя автора 12/700 цветом (#FF8AB8, #7CC8FF, #B8F57C); свой — #071209, border 1px #2E8B3A, текст #B8FFC2, мета PT Mono 10 #3CFF5A; третья галочка #F2D21A.
- **Список чатов:** строки-«треки» 60px с номером «1.», имя LCD-зелёным, счётчик amber-квадрат.
- **МАКС:** окно-диалог в стиле Windows (синий тайтл `#0A246A→#3A6EA5`, «МАКС — Внимание!», «Ваш кодек устарел…», кнопки «Обновить» / «Стереть»).

### DOS (C)
- **Шрифт:** IBM Plex Mono 400/600/700 везде (14/1.5 базовый).
- **Цвета:** фон `radial-gradient(ellipse at 50% 45%,#06200C,#010603 80%)` + сканлайны rgba(51,255,102,.035); фосфор #33FF66 с `text-shadow:0 0 6px rgba(51,255,102,.55)`; тусклый #1F9A40; тёмно-зелёная подложка F-клавиш #0E5A22 (текст #B8FFC8); янтарь #FFB000 (свои сообщения, предупреждения, отбой; текст на янтаре #1A0E00).
- **Рамки:** `border:3px double #33FF66`, заголовок рамки — по центру верхней кромки на фоне (`C:\СООБЩЕНИЯ`). Выделенная строка — инверсия (фон #33FF66, текст #020A04, без свечения).
- **Лента — IRC-стиль:** `[13:58] <Мама> текст`; свои — янтарём с левой чертой 2px; галочки текстом «✓✓✓ записано на дискету». Ошибка: пунктир #FFB000 + инверсная плашка «! СБОЙ ЗАПИСИ — R=Повторить».
- **Кнопки:** главная — инверсия `[ ENTER ] Войти`; вторичная — рамка 2px. Кнопки звонков подписаны модемными командами: ATA (принять), ATH (сброс/отбой), CAM, MIC, SPK, FLIP.
- **Нижняя полоса F-клавиш** вместо таб-бара: `1 Чаты · 2 Абон · 3 Наст · 7 Новый` (активная — инверсия). Меню сообщения — F1…F8.
- **Изображения** (стикеры, Олег) перекрашиваются в фосфор: `filter: grayscale(1) sepia(1) hue-rotate(70deg) saturate(4) brightness(.9)`.
- **Тексты:** вход — загрузка OLEG-DOS 6.22; ошибка — «(П)рервать, (П)овторить, (И)гнорировать?»; нет связи — `ATDT 8-800-OLEG … NO CARRIER`; МАКС — антивирус «Доктор Олег» нашёл МАКС.EXE; настройки — CONFIG.SYS (`ALARM_NEWBIE=ON`), выбор люминофора P1 зелёный / P3 янтарь / P4 белый.

## Interactions & Behavior
- **Навигация:** телефон — стек (Сообщения → Переписка → Профиль чата); ≥768 — две колонки (экран 23).
- **Отправка:** Enter / «Передать». Пустое поле → вместо «Передать» кнопка микрофона. Галочки: 1 сразу → 2 «Получено» → 3 «Записано на дискету» (прочитано). В Денди вместо галочек звёзды.
- **Набор:** «<Имя> передаёт сигнал…» в шапке + индикатор в ленте (точки / мини-эквалайзер).
- **Ошибка отправки:** пузырь полупрозрачный с пунктиром, красный «!», тап → повтор.
- **Голосование:** таймер 5:00; решает большинство посвящённых; ничья — в пользу новичка. После голоса кнопки → «Твой голос: …» + «Передумал» до конца таймера. Отклонённый остаётся «Олегом#N» навсегда (экран 06).
- **Звуковые:** тап play/pause, один трек одновременно, прогресс красит столбики волны, время — остаток; «в текст» — расшифровка под пузырём.
- **Запись:** удержание микрофона → запись (13); отпустить → отправить; влево >100px → отмена; вверх до замка → режим без удержания. Короткий тап по микрофону переключает микрофон ⇄ камеру (кружок, 14; лимит 60 с).
- **Кружки:** тап — проигрывание со звуком, кольцо прогресса; повторный тап — пауза.
- **Звонки:** аудио/видео 1:1. Свернуть → плашка «На связи 02:14» над текущим экраном. В чате после звонка — служебная запись / «Пропущенный сигнал» + «Перезвонить». Входящий — пульсация (эквалайзер/кольца).
- **Меню сообщения:** долгое нажатие на пузырь → реакции + меню (11). «Стереть у всех» — с подтверждением.
- **МАКС-спам:** раз в день в случайный диалог; можно запустить вручную из Пульта.
- **Тайминги анимаций:** нажатие кнопки 120ms ease-out (в пиксельных темах — сдвиг на 2–3px вниз-вправо и уменьшение тени вместо scale); появление пузыря translateY(6px)→0 + opacity 180ms.

## State Management
- `theme`: `winamp | dos | dendy | dacha | mix` + `skin` (вариант внутри темы).
- `session`: ник, статус `initiated | candidate | rejected`, номер Олега#N, `isSuperAdmin`.
- `chats[]`: id, name, type (`direct|group`), avatar, members, online, unread, lastMessage, isCandidate.
- `messages[chatId][]`: id, kind (`text|sticker|voice|circle|max|service|call`), author, text, media {url, duration, waveform[]}, time, status (`sending|sent|delivered|read|failed`), reactions.
- `typing[chatId]`, `vote` {candidateId, invitedBy, endsAt, for, against, myVote}, `player`, `recorder` {mode, state `idle|holding|locked`, elapsed, cancelOffset}, `call` {peerId, kind, direction, state, startedAt, mic, cam, speaker, quality}, `invites[]` {code, url, expiresAt, usedBy}.
- `settings`: alarmNewbie, messageSound, readTick, тема-специфичная опция, notificationLevels (эквалайзер).
- Realtime: WebSocket (сообщения, набор, голосование); Web Push (тревога «Новый абонент», входящие звонки).
