# Handoff: мессенджер «Олег» — стиль Y2K

## Overview
«Олег» — камерный мессенджер для друзей и семьи (5–30 человек), шуточная пародия на государственный мессенджер МАКС. Слоган: «НеМногонациональный мессенджер Олег». Платформы: iOS (PWA), Android, веб. Тон интерфейса — шутки эпохи Y2K (пейджеры, дискеты, «киберпространство», Проблема 2000), но удобство обычного мессенджера уровня Telegram: кнопки там, где их ожидают.

Пакет покрывает: вход (экран 1), список чатов (5), переписку (6), звуковые послания и кружки (13), звонки аудио/видео (15) + широкий веб-макет «список + переписка».

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, сделанные в HTML**: прототипы, показывающие внешний вид и поведение, а не продакшен-код. Задача — **воссоздать эти макеты в целевом окружении** (React/Next, Vue, SwiftUI, React Native и т.п.) по его принятым паттернам. Если кодовой базы ещё нет — выбрать подходящий стек (рекомендация: React + TypeScript, PWA с service worker и Web Push; WebRTC для звонков).

Открыть макеты: положить папку целиком и открыть `*.dc.html` в браузере (рядом должны лежать `support.js` и `uploads/`). Это холст с артбордами; каждый артборд подписан id (4a, 4b…).

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, радиусы, тени и копирайт — финальные. Воспроизводить максимально точно. Иконки — простые SVG прямо в разметке (можно заменить на библиотеку с тем же визуальным весом, stroke ≈2px, заливка для микрофона/камеры/трубки).

## Interactions & Behavior
- **Навигация**: телефон — стек (Сообщения → Переписка → Профиль чата); ≥768 — две колонки.
- **Отправка**: Enter / «Передать». Галочки: 1 сразу → 2 «Получено» при доставке → 3 «Записано на дискету» при прочтении (в прототипе — таймеры 0.7 с и 2.2 с).
- **«Передаёт сигнал…»** — индикатор набора в шапке и пузырём с тремя неоновыми точками в ленте.
- **Ошибка отправки**: пузырь полупрозрачный с пунктирной обводкой, красный «!» и «Саботаж… / Ошибка Y2K! Повторить».
- **Голосование за нового абонента**: таймер 5:00; решает большинство посвящённых; ничья — в пользу новичка. После голоса кнопки заменяются на «Твой голос: впустить / отключить» + «Передумал» (до конца таймера).
- **Звуковые**: тап play/pause; один трек одновременно; прогресс красит столбики волны; время показывает остаток. Тап по волне — перемотка (добавить). «в текст» — расшифровка под пузырём.
- **Кружки**: тап — проигрывание со звуком, кольцо прогресса; повторный тап — пауза.
- **Звонки**: аудио/видео 1:1 (WebRTC). Свернуть звонок → плашка «На связи 02:14» над текущим экраном. В чате после звонка — служебная запись «Видеосвязь · 12:40» / «Пропущенный сигнал».
- **Анимации**: кнопки-«пластик» при нажатии `transform: scale(.96)` + усиление inset-тени, 120ms ease-out. Появление пузырей — translateY(6px)→0 + opacity, 180ms. Пульсация колец входящего звонка — см. 5d.

## State Management
- `session` (ник, статус посвящения: `initiated` | `candidate` | `rejected`, номер Олега#N).
- `chats[]`: id, name, type (`direct`|`group`), avatar (цвет/картинка), members, online, unread, lastMessage.
- `messages[chatId][]`: id, kind (`text`|`sticker`|`voice`|`circle`|`max`|`service`|`call`), author, text, media {url, duration, waveform[]}, time, status (`sending`|`sent`|`delivered`|`read`|`failed`).
- `typing[chatId]`: кто набирает.
- `vote`: candidateId, invitedBy, endsAt, for, against, myVote.
- `player`: playingMessageId, progress.
- `recorder`: mode (`voice`|`circle`), state (`idle`|`holding`|`locked`), elapsed, cancelOffset.
- `call`: peerId, kind (`audio`|`video`), direction, state (`ringing`|`connecting`|`active`|`ended`), startedAt, mic, cam, speaker, quality.
- Realtime: WebSocket для сообщений/набора/голосования; Web Push для тревоги «Новый абонент» и входящих звонков.

## Ключевые механики (из брифа)
- Вход только по нику и паролю; регистрация — только по ссылке-инвайту от любого участника.
- Новичок сразу попадает в чат как «Олег#N» (стандартный аватар `oidea.svg`) и может писать.
- Всем посвящённым — тревога «Новый абонент» с таймером 5 мин. Отклонённый навсегда остаётся «Олегом#N»: пишет и приглашает, но не голосует и не меняет имя/аватар.
- Раз в день в случайный диалог приходит МАКС-«пейджер».
- Супер-админ: «Пульт» — читает все чаты, удаляет сообщения, исключает, пересматривает голосование, вручную запускает МАКС. *(Экран ещё не нарисован.)*
- Ещё не нарисованы в Y2K: регистрация по инвайту, ожидание вердикта, панель 15 стикеров, новый чат/инвайт, профиль, настройки, пульт, установка PWA, меню сообщения. Делать в том же визуальном языке.
